# Mangowit 可运行性修复设计

## 目标

让解压后的 Django 项目在没有 MySQL 的本机环境中可以使用 SQLite 完成安装、迁移、启动和主要页面访问，同时保留通过环境变量连接 MySQL 的能力，并消除已复现的 6 个 HTTP 500 页面错误。

## 范围

本次修复只处理运行环境、已复现页面错误和对应回归测试，不重做页面视觉、不补造原始业务数据，也不扩展现有功能。

完成标准：

- 新环境按说明安装依赖后，可执行迁移并启动开发服务器。
- 默认使用项目内 SQLite；明确设置数据库环境变量时可切换 MySQL。
- Django 系统检查通过。
- 已测试的 42 个 GET 路由不再返回 500；不存在的话题详情返回 404。
- 首页、静态资源和至少一条主要导航在真实浏览器中正常显示。

## 方案选择

采用“SQLite 默认、MySQL 可选”。相比只使用 SQLite，此方案保留部署弹性；相比强制 MySQL，它不要求每台开发机先安装和配置数据库服务。实现不引入额外数据库配置库，直接使用 Django 原生设置和环境变量，减少依赖。

## 配置与依赖

`mangowit/settings.py` 默认将 `db.sqlite3` 作为数据库。设置 `MANGOWIT_DB_ENGINE=mysql` 后，从 `MANGOWIT_DB_NAME`、`MANGOWIT_DB_USER`、`MANGOWIT_DB_PASSWORD`、`MANGOWIT_DB_HOST` 和 `MANGOWIT_DB_PORT` 读取 MySQL 配置。

Django 密钥、调试模式、允许主机和 Neo4j 凭据改由环境变量读取。开发环境允许安全的本地默认值；源码不再保留现有数据库和 Neo4j 明文密码。

新增：

- `requirements.txt`：Django 5.1–5.2 与 Pillow。
- `requirements-mysql.txt`：引用基础依赖并增加 `mysqlclient`。
- `.env.example`：只包含无敏感信息的配置示例。
- `README.md`：记录虚拟环境、安装、迁移、启动、测试和 MySQL 切换命令。

## 页面错误修复

### 旧答题入口

`/quiz/` 和 `/question/` 使用的旧模板引用了不存在的 URL 名称与缺失上下文。现有站点实际入口是 `/category_select/`。两个旧入口改为重定向到分类选择页，避免维护两套不一致流程。

### 个人中心

`sex_education_app/views.py` 中后定义的无装饰器 `profile` 覆盖了前面的登录保护版本。合并为一个带 `login_required` 的实现：未登录用户跳转到登录注册页，已登录用户可查看和更新资料。

### 关卡选择

无参数的 `/level_select/` 无法调用要求 `category` 的视图。该兼容入口重定向到分类选择页；带分类参数的路由保持原行为。

### 教育资讯首页

新增 `education_index.html`，展示最多五条文章；数据库为空时显示明确的空状态，并提供返回新闻资讯页面的导航。

### 话题详情

使用 `get_object_or_404` 查询话题。记录不存在时返回标准 HTTP 404，而不是尝试渲染缺失模板并产生 500。话题存在时继续渲染原详情模板。

## 测试策略

先编写失败测试并确认其针对当前缺陷失败，再逐项实现最小修复：

- 配置测试：默认数据库为 SQLite；MySQL 环境变量组合生成正确配置。
- 路由测试：`/quiz/`、`/question/`、无参数 `/level_select/` 返回预期重定向。
- 认证测试：匿名访问个人中心跳转登录页；登录用户访问返回 200。
- 模板测试：教育资讯首页在空数据库和有文章时均返回 200。
- 错误处理测试：不存在的话题返回 404，存在话题返回 200。
- 冒烟测试：此前检查的公开 GET 路由均不返回 500。

最终运行完整 Django 测试、`manage.py check`、数据库迁移检查和真实浏览器验证。

## 数据与兼容性

压缩包中的 SQLite 文件当前无表；首次运行必须执行 `python manage.py migrate`。修复不会删除或伪造数据。若用户以后取得原 MySQL 数据，只需设置环境变量并安装 MySQL 额外依赖即可连接，不需要修改业务代码。

## 风险与限制

- 当前压缩包没有原 MySQL 数据，因此只能验证结构和空数据状态，无法恢复历史账户、文章或话题。
- `mysqlclient` 在 macOS 上可能需要 MySQL 开发头文件和 `pkg-config`；基础 SQLite 启动不受影响。
- 部分页面依赖外部 CDN，断网时字体或图标样式可能降级，但 Django 页面仍应返回成功响应。
